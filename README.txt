Photo Memo PWA

使い方:
1. フォルダー内のファイルを同じ場所に置き、HTTPSの静的Webホスティングで公開してください。
2. ブラウザーでアクセスし、アカウントを作成して写真を投稿します。
3. ホーム画面に追加すると、インストール型アプリとして利用できます。
4. 最初の読み込みとキャッシュ完了後はオフラインで動作します。
5. 設定からJSONバックアップを定期的に書き出してください。

注意: file:// で直接開くとService Workerが使えません。ローカル開発では localhost サーバーを使ってください。
保存データはブラウザーのIndexedDBにあります。ブラウザーのデータ消去時には消えるため、バックアップを推奨します。
